### G-16 — THE CROSSING'S OWN CODEC STILL CARRIES THE TAG SYSTEM, AND THE 2026-10-21 JSON RULING WAS READ AGAINST THE FILE TIER'S CODEC ALONE (parked 2026-10-22 at the architect's observation)
