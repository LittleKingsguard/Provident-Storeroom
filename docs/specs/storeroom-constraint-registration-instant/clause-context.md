## §2 · THE SEVENTH MEMBER ITSELF — `write`, DECLARED ONCE

**SHAPE.** **`write(address, tier, value) -> WriteRecord`** — **the store's own `write`'s FIRST THREE positions, and no fourth.**

**`address`** — an address in the store's own domain: an array of string keys or non-negative integer indices, the empty array included; **a nested address does not create its parent, and a write whose parent is a leaf or absent answers the store's own `WriteParentNotLink` / `AddressNotFound`** (`src/store.rs:2154`-`:2171`) — **this is why `PIN-9` says a pair whose parent is absent cannot be rescued by its own repair.** **`tier`** — REQUIRED at this position exactly as it is at the store's `write` (`PAR-JS-7`); **an absent tier and a supplied `undefined` both answer the store's own `AddressMalformed`, and neither folds.** **`value`** — the store's own admitted value tree; **a value the Java-Script crossing refuses answers the boundary's own `ValueRefusedAtBoundary` before the store is reached, and a value the store's own taxonomy refuses answers `ValueNotAdmitted`** (`src/error.rs:325`-`:328`, `:353`-`:356`).

**THE COMMIT IS NOT A POSITION, AND A SUPPLIED FOURTH IS REFUSED.** **The route names THE REGISTRATION'S OWN `CommitRecord`** — the record the registration built and the record the repair's `pending` copy-carries — **and a call that supplies a fourth position is REFUSED BEFORE ANY STORE ACT, whatever that position's class: the test is THE ROUTE'S OWN and NOT the store's commit-position test, because that test ACCEPTS any object carrying an own present `pending`** (`bindings/js/src/entry/delivery.mjs:27`-`:54`, and its accepting arm at `:39`) **— which is exactly the record a repair holds, so re-using it would admit the call this clause forbids.** **The refusal's form: a `TypeError` whose `status` member is ABSENT and whose sentence names the route's arity and its reason; on the commit position's own precedent such a refusal is thrown unwrapped and carries NO `log` member** (`bindings/js/index.mjs:370`-`:372`) **— and the `log` member is not pinned here for any other class refusal, several of which do carry `log: []`.** **`PIN-10`'s *"no status is minted"* is unharmed: this is the package's class refusal and not a store code, and the `TypeError` class is the one this surface already uses at a class position.** **The ground is `D-91` (ii): a route that writes outside the registration's commit does not satisfy the row, so the caller may not name one.** **Nothing lands on a refused call.**

**THE ANSWER IS THE STORE'S OWN `WriteRecord` — `{ op, watched, triggered }`** (`bindings/js/index.mjs:446`-`:450`) — **and the repair's declared use of it is one line: `return { ok: true, op: answer.op }`.** **The credit is then the existing rule and no new rule** (`PIN-7` (ii)): the op is read as the return's own member, it is not already held by the synthetic attempt, **and with the invoked-for op `null` the ordinal ground is not applied** (`bindings/js/src/entry/kernel-foundations.mjs:1101`-`:1103`).

**WHAT THE WRITE DOES NOT DO, EACH DECLARED BECAUSE SILENCE HIDES A STATE A CONSUMER MEETS:** **it appends no `constraint-check`, no `repair-run` and no terminal `outcome` entry, and it runs no pass of its own** (`PIN-6` (v)); **it delivers no listener**; **it composes no rollback, and a refusal of the registration leaves it standing** (`PIN-7` (iv)); **and it answers no `KC` token — it is a store verb's record, not the kernel's form.**

**WHAT IT REFUSES AND HOW THE REFUSAL CROSSES: UNCONVERTED, UNCATCHED AND UNMARKED — the store's own `{status, message}` in the store's own form.** **The repair that does not catch it therefore fails the registration by `PIN-6` (iv)'s own arm**, which is the arm the tree already declares as *"A REPAIR WHOSE BODY THROWS IS A FAILED REPAIR AND THE REGISTRATION IS REFUSED"* (`kernel-registration.mjs:575`-`:585`, RE-SPELLED 2026-11-02 from `:498`-`:508`).

**AND THE MEMBER IS NOT A COPY OF THE STORE: it is a route the kernel binds to the instance the registration is constructing, so it answers this store and no other, and it is created at the invocation's own instant.** **A repair that holds it past the registration holds a function that names a commit that has closed; no clause declares that a later call lands, and none is claimed here.**
