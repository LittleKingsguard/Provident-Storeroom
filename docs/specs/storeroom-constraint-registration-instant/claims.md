# `claims` — the claim ledger (`§1`) and the citation re-spellings (`§2`)

**WHAT THIS PART IS.** **One row per pinnable claim, each with its ONE resolving citation, its class and its status; then the citation re-spellings as a checked REQUIREMENT list.** **Each path this directory prints appears in `§2` exactly once, with the reading it was taken at and whether THIS PASS read it at its own bytes or CARRIED it from a record that did.** **A row that says `CARRIED` is not a weaker claim — it is the same claim with its provenance printed, so no reader has to guess which of the two it holds.** **No citation here names an archived path as a target** (`D-85` item 2; `contract.md §4` item 4).

**THE THREE CLASSES, THIS DIRECTORY'S OWN:** **`[R]`** a RUN through the published entry (`bindings/js/index.mjs`) at a stated date · **`[M]`** a path or line measurement (a file read, a line count, a tracked-path census) · **`[T]`** a text claim read at its own bytes (`path:line`, named).
