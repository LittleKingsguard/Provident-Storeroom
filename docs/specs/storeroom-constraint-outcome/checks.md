## §3 · WHAT NEITHER THE BYTE CHECK NOR THE GATE CHECKS ESTABLISH

1. **They establish nothing about behaviour.** A green `§1` is evidence that the appended item **exists, sits where it must, and says what it must** — **never** that the code reads own members at the registration instant, and never that either instant's read is correct. **The properties belong to the code units, and this unit records a divergence rather than measuring one** (`contract.md §2` requirement `15`).
2. **They cure nothing.** The site stays **a REGRESSION against a closure**, and the cell closes at the event its own revisit condition names and at no earlier act (`contract.md §2` requirement `11`).
3. **They repair none of the corpus's other dead citations.** Those citations are outside this check's searched set **by design** — the check tests the appended item's own bytes and no other byte of that document — and their remedy is the successor unit's whole scope, which stays UNSTARTED (`contract.md §2` requirement `18`).
4. **They re-derive no closure predicate.** The corpus's closure arithmetic is **not** recomputed, printed or reconciled here, a pass that needs it being free to re-derive it and this pass not needing it (`contract.md §2` requirement `18`).
