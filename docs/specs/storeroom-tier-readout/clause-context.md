## §1 · THE MEMBER DOCBLOCK — ONE SITE, FIVE REQUIRED FACTS, SIX FORBIDDEN MOVES

**THE SITE.** **ONE docblock, inside `bindings/js/index.d.ts`, immediately above (or beside) the single member line `readTiered(address: Address, tier?: TierSet): …;` that lands beside `readLiteral` at `:995`.** **It is the ONLY prose site this unit owns; `bindings/js/index.d.ts` is the CANONICAL home of the declaration and its `typecheck/` copy is staged from it (`package.json:8`), so a mark written in the copy is lost at the next `typecheck:stage`.** **NO SECOND PROSE SITE IS OWED** (`Q-4`, **ANSWERED** by `D-121-quater` item 2 — *"Docblock only"*, `strata/decisions.md:6237`; the row that declines a rule, a refusal and a strip at `:6246`): no guide sentence, no `README` sentence, and no release-note prose beyond `§3`'s section.

**THE FIVE REQUIRED FACTS — each one is owed by a named clause, and each is owed IN WORDS rather than by a signature.**

1. **WHAT THE VERB ANSWERS, KIND BY KIND, AS THE TOTAL FUNCTION `PIN-3` FIXES.** **Required: that an OBJECT node answers `{ _tier, …members }` with its members inline; that an ARRAY node answers `{ _tier, value: [ … ] }`; that a LEAF node answers `{ _tier, value: <the literal> }`; and that THEREFORE every node of the answer is an object and no node's answer is a primitive.** **Ground: `D-121-ter` item 1 (`strata/decisions.md:6213`).**
2. **WHAT `_tier` REPORTS, AND THAT IT IS NEVER A SET.** **Required: that each node's `_tier` is THAT NODE'S OWN tier — an object's and an array's its own anchor tier, a leaf's the tier of the version the read selected; that it is one of `Tier`'s three tokens (`bindings/js/index.d.ts:179`) and never an array; and that an answer's fields are the persistence ladder it walked and never one tier repeated.** **`D-121-ter` item 2 (`strata/decisions.md:6215`), read with `PIN-4`.**
3. **THE COLLISION, DECLARED RATHER THAN LEFT TO BE DISCOVERED.** **Required: that a caller-stored member named `_tier` is **NOT DELIVERED** by this verb — the minted field wins — and that the DEFAULT `read` at the same address and tier still answers the caller's stored value, so nothing is destroyed and the truth is reachable; and that this is the ONE lossy field, in this ONE verb.** **Ground: `D-121-ter` item 3 (`strata/decisions.md:6217`), read with `PIN-5` (i)–(iv).**
4. **THE WRITE-BACK CONSEQUENCE, WHICH IS THE OBLIGATION THE RULING NAMES AS A DOCBLOCK RATHER THAN A RULE.** **Required, in words a consumer cannot mistake: that a `readTiered` answer handed to `write` is stored **AS ORDINARY DATA** — `_tier` members and the `value` wrappers become the caller's own stored members — because the copy-in walk reads `Object.keys` (`bindings/js/src/entry/carrier.mjs:364`); and that NO RULE GOVERNS THIS: no clause forbids it and no clause blesses it.** **Ground: `D-121-ter`'s un-settled paragraph, verbatim — *"no clause forbids it and no clause blesses it … until then a docblock must SAY SO rather than leave it discovered"* (`strata/decisions.md:6227`), which is the ONE obligation this unit's prose exists to discharge.** **AND IT IS LAW RATHER THAN A DEFAULT, BECAUSE `Q-4` IS ANSWERED: `D-121-quater` item 2 (`strata/decisions.md:6246`) declines a REFUSAL and declines a STRIP by name and makes this docblock the ONE obligation — *"nothing is forbidden and nothing is blessed"*.** **THE DOCBLOCK MUST NOT CLAIM THAT A RULE EXISTS OR THAT A VALUE IS REFUSED.**
5. **THAT THE VERB IS NOT A VERSION-SET READOUT.** **Required: that the answer reports WHICH VERSION WON and never which versions stand — so a key holding a `file` and a `mem` version and a key holding only the winning version answer the same shape; and that the surface's one tier-SET answer remains `delete`'s `receipt.tiers`.** **Ground: `PIN-9` (vi), read with `bindings/js/index.d.ts:647`–`:671`.**

**THE SIX FORBIDDEN MOVES — a docblock that does any one of them is a gate-8 finding.**

- **A SENTENCE THAT `read` OR `readLiteral` CHANGED, gained a position or gained a default** — `PIN-6` (i) forbids the change and `D-121-ter` item 4 is his own words (`strata/decisions.md:6219`).
- **A SENTENCE THAT `_tier` IS A SET, A MAP, A COUNT, A `null` WHERE A NODE HAS NO TIER, OR A FOURTH TOKEN.** **`PIN-4` (v) fixes the three tokens and `PIN-3` (i) forbids a node without one.**
- **A SENTENCE THAT AN OMITTED MEMBER CARRIES A `_tier`** — `PIN-9` (ii): the omitted member does not exist in the answer, so nothing is stamped `null`.
- **A SENTENCE THAT `value` CAN BE SHADOWED OR RENAMED, OR A SENTENCE THAT A CALLER'S OTHER MEMBER IS TOUCHED** — `PIN-5` (iv) proves `value` is never shadowed and `PIN-5` (i) confines the loss to `_tier`.
- **A SENTENCE THAT NAMES A RULE FOR THE WRITE-BACK, A STATUS MINTED FOR IT, OR A REFUSAL** — the ruling rules nothing (`strata/decisions.md:6227`), and `D-121-quater` item 2 (`:6246`) declines a REFUSAL and a STRIP by name.
- **A RE-PRINT OF THE ARM TABLE, OF A MEMBER CENSUS, OF THE `67`-SITE FIGURE, OR OF THE GUIDE'S SENTENCE** — a signature docblock is not a register; **and the guide's sentence is now `D-122`'s correction (⟶ CORRECTED 2026-11-06, `strata/decisions.md:6269`, at `docs/guides/package-use.md:386`–`:387`), which this unit neither cites approvingly nor corrects** (`PIN-9` (vii)).
